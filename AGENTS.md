# CoverNerve Rank Logic Die

This package root owns the placement-independent executable projection of the
pinned CoverNerve rank language model and its canonical typed RMN pinout. It is
a logic die and software package, not an enterprise or mounted node.

- Input is exactly `CoverNerveRankRequest.v1`; output is exactly
  `CoverNerveRankResult.v1`.
- Identity is RFC 8949 core-deterministic CBOR and RFC 6920 `ni`.
- The die has no filesystem, network, credential, account, model, or persistent
  state access and declares an empty effect set.
- The proved Lean declarations, this separately implemented executable
  projection, its bounded assays, a package release, and a mounted enterprise
  occurrence are distinct evidence grades.
